# Architecture decisions

Authority: current. This file is the current index of the decisions D1 to D90 and the recommendations R1 to R8: what each decided, its status today, which later decision changed it and which current document holds the resulting rule. The complete record of every decision (its decision, evidence and stated rationale) is in `history/decision-log.md` up to D78 and, since D79, in `history/decision-log-d79.md` (started because the first log reached its size recommendation); both are historical: read them to investigate a decision, not to find a current rule. Each row's Record links to the log that holds it. A new decision takes the next free ID, D91 (`README.md` §Maintaining these documents).

Status words: "current" is in force; "extended", "narrowed" or "refined" means that a later decision, named under Changed by, changed its scope; "superseded" means it no longer applies; "completed" marks the record of a one-time event, such as a publication or a validation. Current rule names the document or engineering rule that states the rule today; "—" means none. Labels such as §AC name validation records (`history/README.md` §Validation record index).

Roadmap step 9, Phase 3 (2026-11-17) turned this file into the index. The decisions were one table whose rows after D15 GitHub showed as plain text; the history file gives each its own subsection.
