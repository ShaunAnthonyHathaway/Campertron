## Solution
`Campertron.sln` [V] contains 6 projects: `CampertronConsole`, `CampertronLibrary`, `CampertronGUI`, `CampertronUnitTests`, `CampertronGUITests` (added with the Avalonia 12 migration), and `docker-compose` (`docker-compose.dcproj`).

## Projects

### CampertronConsole (`CampertronConsole/CampertronConsole.csproj`)
- Exe, `net11.0`, `Nullable` enabled, `DockerDefaultTargetOS=Linux` [V]. Packages: Azure Containers Tools Targets 1.22.1 [V]. EF Core Tools and a redundant FileProviders.Embedded reference were removed in D31 (the library brings everything the console uses).
- `Program.cs` [V]: `--version` (exactly that one argument) prints `RuntimeInfo.Describe` and returns 0; otherwise it sets `Load.FirstStartNotice` and returns `Load.RunConsole(Load.GetConfig())` inside a `try` (since D64: 1 when email mode had no search to check, 0 after an `outputTo: UnitTest` start): a failure is reported by `ConsoleUi.ReportFailure` (standard error; since D67 with all the run's settings, so the SMTP passwords and ntfy's token and topic are hidden) and `Main` returns 1 (D34). No other argument parsing.
- `Dockerfile` [V]: multi-stage, multi-architecture build. `mcr.microsoft.com/dotnet/sdk:11.0` runs on `$BUILDPLATFORM` and restores, builds and publishes the console with `-a $TARGETARCH` (framework-dependent, `UseAppHost=false`); the final stage is `runtime:11.0` (Ubuntu 26.04 since D31). `COPY . .` brings the root `global.json` into the build stage, so the build and publish steps resolve the image's SDK 11 through the same policy. `VERSION`/`REVISION` build args and OCI labels (title, description, source, MIT license, version, revision). `ENTRYPOINT ["dotnet", "CampertronConsole.dll"]`; `USER app`. Needs BuildKit.
- `Properties/launchSettings.json` [V]: profiles `CampertronConsole`, `WSL`, `Docker`.

### CampertronLibrary (`CampertronLibrary/CampertronLibrary.csproj`)
- `net11.0` [V]. Embeds `content/RecreationDotOrg.db.br` as an `EmbeddedResource` [V]. It is the Brotli-compressed `RecreationDotOrg.db` (26,616,039 bytes; 226,471,936 bytes extracted; SHA-256 of the DB `8712856097a91ee1…`), built from the RIDB export of 2026-11-10 with only the 6 used tables. It replaced `content/RecreationDotOrg.zip` (81,232,118 bytes, holding a 328,126,464-byte DB dated 2024-11-18).
- Packages [V]: EF Core Sqlite 11.0.0 (brings Microsoft.Data.Sqlite 11.0.0, SQLitePCLRaw 3.0.5 and the native `SQLite` 3.53.4 package), FileProviders.Embedded 11.0.0, Newtonsoft.Json 13.0.3, YamlDotNet 16.3.0 (D31; EF Core Tools removed).
